## ZED ZONE: Russian Translation Pack (`v1.0.0`)

All-in-one Russian translation and mixed EN/RU localization fix pack for four popular **ZED ZONE** community mods. Automatically activates only for the mods you have installed (works with any 1 to 4 mods):

- **Apocalypse RV | Mobile Survival Base (`3842730326`):** Full Russian translation of all `286/286` UI strings (dashboard, upgrades, utilities, power/water/climate, roof turret, prompts & errors) + Cyrillic font glyph preloading.
- **Supply Drop (`3840679964`):** Russian translation of all helicopter and crate notifications, all 8 compass directions, and distances.
- **ZedCars: Apocalypse Garage (`3845083252`):** Fixes mixed EN/RU vehicle names (caused by `GameLanguage.English` lookup), synchronizes `ZedLoc` to Russian, and ensures full Russian kit item names and descriptions.
- **ZedQuests: Living World (`3845083095`):** Fixes mixed EN/RU `ZedLoc` & `WorldLoc` sync, preserves native Russian names/descriptions on quest items, and clears the Director item name cache on language change.
- **Configurable:** Set `LanguageMode` (`auto` / `ru` / `off`) and toggle each module individually in `BepInEx/config/com.druid.zedzone.russianmodpack.cfg`.

Requires third-party [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader is not a mod by druidqwerty.

## ZED ZONE: Пак русских переводов (`v1.0.0`)

Единый мод-русификатор и фикс смешанной EN/RU локализации для четырёх популярных модов **ZED ZONE**. Автоматически активирует только те модули, чьи базовые моды у вас установлены (работает с любым сочетанием от 1 до 4 модов):

- **Apocalypse RV | Mobile Survival Base (`3842730326`):** Полный русский перевод всех `286/286` строк интерфейса (приборная панель, тюнинг, системы быта, вода/генератор/климат, турель, подсказки и ошибки) + предзагрузка кириллицы в шрифт.
- **Supply Drop (`3840679964`):** Русский перевод всех уведомлений о вертолёте и ящиках снабжения, всех 8 сторон света и дистанций.
- **ZedCars: Apocalypse Garage (`3845083252`):** Исправление смешанной EN/RU локализации: русские названия машин вместо отката на `GameLanguage.English`, синхронизация `ZedLoc` на русский и полные русские названия/описания предметов обвеса.
- **ZedQuests: Living World (`3845083095`):** Исправление смешанной EN/RU локализации: синхронизация `ZedLoc` и `WorldLoc` на русский, сохранение русских названий/описаний квестовых предметов и сброс кэша имён директора при смене языка.
- **Гибкий конфиг:** Выбор `LanguageMode` (`auto` / `ru` / `off`) и раздельное включение каждого из 4 модулей в `BepInEx/config/com.druid.zedzone.russianmodpack.cfg`.

Требуется сторонний [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader не является модом druidqwerty.
