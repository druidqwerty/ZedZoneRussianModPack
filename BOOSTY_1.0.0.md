## ZED ZONE: Russian Translation Pack (`v1.3.0`)

All-in-one Russian translation and mixed EN/RU localization fix pack for five popular **ZED ZONE** community mods. Automatically activates only for the mods you have installed (works with any 1 to 5 mods):

- **Apocalypse RV | Mobile Survival Base (`3842730326`):** Full Russian translation of all UI strings for `v0.9.4+` (`RvLocale`, `399/399`) and `v0.7.5–v0.9.2` (`534` entries total: RV-01 terminal, drive modes, Portal Summoner, upgrades, utilities, power/water/climate, roof turret, prompts & errors) + Cyrillic font glyph preloading and Mod Menu setting descriptions.
- **Supply Drop (`3840679964`):** Russian translation of all helicopter and crate notifications, all 8 compass directions, distances, and all 37 Mod Menu setting descriptions.
- **ZedCars: Apocalypse Garage (`3845083252`):** Fixes mixed EN/RU vehicle names (caused by `GameLanguage.English` lookup), synchronizes `ZedLoc` to Russian, and ensures full Russian kit item names and descriptions.
- **ZedQuests: Living World (`3845083095`):** Fixes mixed EN/RU `ZedLoc` & `WorldLoc` sync, preserves native Russian names/descriptions on quest items, and clears the Director item name cache on language change.
- **Spawn Menu — item spawner and kits (`3839284592`):** Full Russian translation of the entire UI (header, search, amounts, all 9 tabs, all 16 item category labels, all 5 default kits, action buttons, footer hints, and all status messages), Cyrillic font selection & glyph preloading, Russian/English layout-aware search input, and all 7 Mod Menu setting descriptions.
- **Configurable:** Set `LanguageMode` (`auto` / `ru` / `off`) and toggle each module individually in `BepInEx/config/com.druid.zedzone.russianmodpack.cfg`.

Requires third-party [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader is not a mod by druidqwerty.

## ZED ZONE: Пак русских переводов (`v1.3.0`)

Единый мод-русификатор и фикс смешанной EN/RU локализации для пяти популярных модов **ZED ZONE**. Автоматически активирует только те модули, чьи базовые моды у вас установлены (работает с любым сочетанием от 1 до 5 модов):

- **Apocalypse RV | Mobile Survival Base (`3842730326`):** Полный русский перевод всех строк интерфейса для `v0.9.4+` (`RvLocale`, `399/399`) и `v0.7.5–v0.9.2` (всего `534` строки: терминал RV-01, режимы хода, портальный маяк, тюнинг, системы быта, вода/генератор/климат, турель, подсказки и ошибки) + предзагрузка кириллицы и переводы описаний в Mod Menu.
- **Supply Drop (`3840679964`):** Русский перевод всех уведомлений о вертолёте и ящиках снабжения, всех 8 сторон света, дистанций и всех 37 описаний настроек в Mod Menu.
- **ZedCars: Apocalypse Garage (`3845083252`):** Исправление смешанной EN/RU локализации: русские названия машин вместо отката на `GameLanguage.English`, синхронизация `ZedLoc` на русский и полные русские названия/описания предметов обвеса.
- **ZedQuests: Living World (`3845083095`):** Исправление смешанной EN/RU локализации: синхронизация `ZedLoc` и `WorldLoc` на русский, сохранение русских названий/описаний квестовых предметов и сброс кэша имён директора при смене языка.
- **Spawn Menu — спавнер предметов и наборы (`3839284592`):** Полный русский перевод всего интерфейса (заголовок, поиск, количество, все 9 вкладок, все 16 типов предметов, 5 стандартных наборов, кнопки, подсказки и статусы), автовыбор кириллического шрифта, ввод кириллицы и латиницы в поиске по раскладке Windows и перевод всех 7 описаний настроек в Mod Menu.
- **Гибкий конфиг:** Выбор `LanguageMode` (`auto` / `ru` / `off`) и раздельное включение каждого из 5 модулей в `BepInEx/config/com.druid.zedzone.russianmodpack.cfg`.

Требуется сторонний [ZED ZONE Code Mod Loader](https://steamcommunity.com/sharedfiles/filedetails/?id=3834614258). Code Mod Loader не является модом druidqwerty.
